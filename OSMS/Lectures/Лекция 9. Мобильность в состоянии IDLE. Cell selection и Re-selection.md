
[[ОСМС Лекция 9.]]

---

## 1. Что такое мобильность в состоянии IDLE?

Когда UE находится в **режиме ожидания (IDLE)**:
- **Нет активного соединения** с сетью,
- **Нет выделенных радиоресурсов**,
- Но UE **должен оставаться доступным** для входящих вызовов (через **пейджинг**).

Чтобы это работало, UE **самостоятельно ищет и выбирает** наилучшую соту для приёма сигнала.  
Это и есть **мобильность в состоянии IDLE**.

> В отличие от **CONNECTED**, где хэндовер управляет сеть, в **IDLE** — **всё делает сам UE**.

---

## 2. Типы измерений для перевыбора сот

UE измеряет **качество радиосигнала** от:
- **Текущей (служебной) соты**,
- **Соседних сот** (список обычно указан в **SIB4–SIB5**),
- **Сот других технологий** (например, LTE → GSM, LTE → 5G NR).

### Основные метрики качества:

| Технология | Метрика | Что означает |
|------------|--------|--------------|
| **GSM** | **RxLev** | Уровень принимаемого сигнала (дБм) |
| **UMTS** | **RSCP** | Received Signal Code Power (дБм) |
| **LTE** | **RSRP** | Reference Signal Received Power (дБм) |
| **LTE** | **RSRQ** | Reference Signal Received Quality (дБ) — учитывает интерференцию |
| **5G NR** | **SS-RSRP** | Signal-to-Interference-plus-Noise Ratio на основе SSB |

> **RSRP** — основная метрика для выбора в LTE.  
> **RSRQ** — учитывает не только мощность, но и **загруженность канала**.

## 3. Cell Selection — первоначальный выбор соты

Происходит при:
- Включении UE,
- Возврате из зоны без покрытия,
- Потере регистрации.

### Условие: **S-критерий**

Сота считается **подходящей**, если выполняется:

$$
\begin{cases}
S_{rxlev} > 0 \\
S_{qual} > 0
\end{cases}
$$

Где:
$$( S_{rxlev} = Q_{rxlevmeas} - (Q_{rxlevmin} + Q_{rxlevminoffset}) - P_{compensation} )$$
$$( S_{qual} = Q_{qualmeas} - (Q_{qualmin} + Q_{qualminoffset}) )$$

Если **ни одна сота не проходит S-критерий** → UE переходит в **режим limited service** (только экстренные вызовы).

## 4. Cell Re-selection — перевыбор соты в IDLE

Происходит, когда UE уже зарегистрирован, но:
- Сигнал текущей соты **ухудшился**,
- Появилась **лучшая соседняя сота**.

### Основной алгоритм: **R-критерий**

Для каждой соседней соты вычисляется **ранг (R)**:

$$
R = Q_{\text{meas}} + Q_{\text{offset}} + Q_{\text{hyst}}
$$

Где:
$$( Q_{\text{meas}} )\quad —\quad измеренное качество\ (RSRP,\ RSRQ\ и\ т.п.),$$
$$( Q_{\text{offset}} )\quad —\quad поправка\ из\ SIB\ (например,\ соседу\ дают\ «бонус»\ или\ «штраф»),$$
$$( Q_{\text{hyst}} )\quad —\quad гистерезис\ (чтобы\ избежать\ «дрожания»\ между\ сотами).$$

> Сота с **наибольшим R** считается **наилучшей**.

### Условия перевыбора:
1. Новая сота имеет **более высокий R**, чем текущая,
2. Условие выполняется **дольше T<sub>reselection</sub>** (чтобы избежать резких переключений),
3. Выполняется **S-критерий** для новой соты.

---

## 5. Перевыбор между сотами разного приоритета

Сеть может **назначать приоритеты** частотам и технологиям через **SIB**.

### Типы приоритетов:
- **Высокий приоритет** (например, 5G NR),
- **Средний приоритет** (LTE),
- **Низкий приоритет** (GSM).

### Правила перевыбора:

#### a) Перевыбор на **высокоприоритетную** соту
- Даже если текущая сота **хорошая**, UE будет **мониторить** высокоприоритетные частоты.
- Если на высокоприоритетной частоте качество **> порога Thresh<sub>high</sub>** в течение **T<sub>reselection</sub>** → **перевыбор**.

#### b) Перевыбор на **низкоприоритетную** соту
- Возможен **только если** текущая сота **ухудшилась**:
$$( S_{rxlev} < \text{Thresh}_{\text{serv, low}})$$
  - И качество низкоприоритетной соты **> Thresh<sub>low</sub>**

> Это позволяет **оставаться на LTE**, даже если поблизости есть GSM — пока LTE «нормально работает».

---

## 🔹 6. Отличия от CONNECTED-мобильности

| Фактор | IDLE (Cell Re-selection) | CONNECTED (Handover) |
|--------|--------------------------|------------------------|
| Кто управляет? | **UE сам** | **Сеть** |
| Требуется ли соединение? | Нет | Да |
| Используются ли RRC-сообщения? | Нет | Да (Measurement Report и др.) |
| Скорость реакции | Медленнее (секунды) | Быстрее (мс) |
| Цель | Энергоэффективность + покрытие | Непрерывность + QoS |

---

| Понятие                     | Формула / Правило                                                 |
| --------------------------- | ----------------------------------------------------------------- |
| **S-критерий**              | $$( S_{rxlev} > 0 ) и ( S_{qual} > 0 )$$                          |
| **R-критерий**              | $$( R = Q_{\text{meas}} + Q_{\text{offset}} + Q_{\text{hyst}} )$$ |
| **Cell Selection**          | При включении или потере сети                                     |
| **Cell Re-selection**       | В IDLE, если появилась лучшая сота                                |
| **Высокий приоритет**       | $$Перевыбор,\ если\ ( Q > \text{Thresh}_{\text{high}} )$$         |
| **Низкий приоритет**        | Только если текущая сота «плохая»                                 |
| **T<sub>reselection</sub>** | Минимальное время удержания условия перед перевыбором             |
