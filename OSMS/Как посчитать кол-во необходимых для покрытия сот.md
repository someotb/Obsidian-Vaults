- Вычислить ThermalNoise = −174 + 10·log10(BW).
    
- Посчитай RxSens = NoiseFigure + ThermalNoise + RequiredSINR (для UE и для BS отдельно).
    
- Подставить в формулу бюджета, найдёшь MAPL_DL и MAPL_UL.
    
- Выбрать модель распространения (COST231 для макро, UMiNLOS для микро/фемто и т.д.).
    
- Решить PL(d) = MAPL по d (инвертируй формулу) — получишь d_DL и d_UL.
    
- Радиус соты R = min(d_DL, d_UL).
    
- Площадь сайта S (в зависимости от числа секторов) и количество сайтов = ceil(общая_площадь / S).
