# 1. Что такое список

**Список** — структура данных, состоящая из узлов (**node**), каждый из которых хранит:
- **данные**
- **ссылку(и) на следующий/предыдущий узел**

Главное отличие от массива: элементы в памяти **не подряд**.

---

# 2. Виды списков

## **Односвязный список (Singly Linked List)**

Каждый узел хранит:
- данные
- **указатель на следующий узел**

Структура:

```
[data | next] → [data | next] → ...
```

## **Двусвязный список (Doubly Linked List)**

```
prev | data | next
```

Узел хранит два указателя:
- на следующий
- на предыдущий

## **Кольцевой список (Circular)**

Последний элемент указывает на первый.

---

# 3. Основные операции и сложность

|Операция|Односвязный список|Двусвязный список|Комментарий|
|---|---|---|---|
|**Доступ по индексу**|O(n)|O(n)|Нужно идти от головы (или хвоста для двусвязного)|
|**Поиск по значению**|O(n)|O(n)|Последовательный обход|
|**Вставка (указатель на место есть)**|O(1)|O(1)|Просто переназначение указателей|
|**Вставка (место надо найти)**|O(n)|O(n)|Сначала поиск нужного узла|
|**Удаление (указатель на узел есть)**|O(1)|O(1)|Дешёвая операция|
|**Удаление (нужно найти узел)**|O(n)|O(n)|Поиск → удаление|
|**Вставка в голову**|O(1)|O(1)|Быстрая операция|
|**Вставка в конец**|O(n), O(1) если есть tail|O(1)|В двусвязном — всегда O(1)|
|**Удаление головы**|O(1)|O(1)|Обновление head|
|**Удаление хвоста**|O(n)|O(1)|В двусвязном есть prev|

---
# 4. Односвязный vs Двусвязный

|Свойство|Односвязный|Двусвязный|
|---|---|---|
|Память|меньше|больше (два указателя)|
|Удаление узла|сложно (нужен prev)|просто|
|Вставка перед узлом|неудобно|удобно|
|Обратный проход|нет|есть|

---

# 5. Ключевые операции

## Односвязный список

- `push_front` — быстро O(1)
- `push_back` — медленно O(n) без хвоста
- вставка после узла — O(1)
- удаление после узла — O(1)

## Двусвязный список

- вставка перед/после узла — O(1)
- удаление узла — O(1)
- доступ по индексу — O(n)

---

# 6. Особые случаи

### ✔ Голова списка (head)

- вставка в голову — быстро
    
- удаление головы требует обновить head
    

### ✔ Хвост списка (tail)

- в односвязном — нет обратной ссылки
    
- поиск хвоста — O(n) (если нет tail)
    
- если tail есть → вставки в конец O(1)
    

---

# 7. Когда список лучше массива

Список лучше, когда:

- много вставок/удалений в середину
- заранее неизвестен размер
- нет необходимости в случайном доступе

Когда массив лучше:

- нужен быстрый доступ по индексу
- много чтения, мало модификаций
- важна эффективность кеша
