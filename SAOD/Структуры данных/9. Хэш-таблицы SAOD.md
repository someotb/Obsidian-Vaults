# **Хеш-таблица**

**Определение:**

- Структура данных для хранения пар **ключ → значение**.
- Основная идея: использовать **хеш-функцию**, которая вычисляет индекс в массиве для ключа.

**Основные операции:**

|Операция|Сложность (средняя)|Сложность (худшая)|Комментарий|
|---|---|---|---|
|Вставка (insert)|O(1)|O(n)|Быстро, если коллизий мало|
|Поиск (search)|O(1)|O(n)|По ключу|
|Удаление (delete)|O(1)|O(n)|По ключу|

---

# **Коллизии**

- Когда два ключа дают один и тот же индекс → **коллизия**.
- Способы разрешения коллизий:
    1. **Метод цепочек (chaining)**: каждый элемент массива хранит список (linked list) пар с этим индексом.
    2. **Открытая адресация (open addressing)**: ищем следующую свободную ячейку (linear probing, quadratic probing, double hashing).

---

# **Особенности**

- Быстрая вставка, поиск и удаление в среднем.
- Не гарантирует порядок элементов.
- Память зависит от размера массива (обычно немного больше числа элементов для уменьшения коллизий).
- Эффективна для **кэширования, подсчёта частот, поиска уникальных значений**.
