## **Графы**

**Определение:**

- Множество **вершин (V)** и **рёбер (E)**: `G = (V, E)`.
- Типы графов:
    - **Ориентированный / неориентированный**
    - **Взвешенный / невзвешенный**
    - **Циклический / ациклический**
    - **Связный / несвязный**

**Представление графа:**

|Способ|Время доступа|Память|Особенности|
|---|---|---|---|
|**Матрица смежности**|O(1) проверка ребра|O(V²)|Удобно для плотных графов|
|**Список смежности**|O(deg(v)) проверка ребра|O(V + E)|Эффективно для разреженных графов|

---

## **Обходы графа**

**1. BFS — Breadth-First Search (Обход в ширину)**

- Использует [[4. Очередь SAOD]] (FIFO).
- Сначала посещаются все соседи вершины, затем их соседи и т.д.
- **Применение:**
    
    - Поиск кратчайшего пути в невзвешенном графе
    - Проверка связности графа

|Операция|Сложность|
|---|---|
|Время|O(V + E)|
|Память|O(V)|

**2. DFS — Depth-First Search (Обход в глубину)**

- Использует [[3. Стек SAOD]] или рекурсию.
- Погружаемся в граф до конца пути, затем откатываемся.

- **Применение:**
    - Топологическая сортировка
    - Поиск компонент связности
    - Проверка наличия цикла

|Операция|Сложность|
|---|---|
|Время|O(V + E)|
|Память|O(V)|

## **3. Алгоритмы на графах**

|Алгоритм|Применение|Сложность|
|---|---|---|
|**Dijkstra**|Кратчайший путь из одной вершины (невзвешенные и с положительными весами)|O(V²) или O(E + V log V) с кучей|
|**Bellman-Ford**|Кратчайший путь с отрицательными весами|O(V * E)|
|**Floyd-Warshall**|Кратчайшие пути между всеми парами вершин|O(V³)|
|**Prim / Kruskal**|Минимальное остовное дерево|Prim: O(E + V log V), Kruskal: O(E log E)|
|**Topological Sort**|Упорядочивание DAG|O(V + E)|
|**BFS для уровней / расстояний**|Поиск кратчайшего пути в невзвешенном графе|O(V + E)|
|**DFS для компонент связности**|Поиск всех компонент|O(V + E)|
