
- - -
- **Принцип**: каждый элемент имеет приоритет; **элемент с наивысшим приоритетом извлекается первым**.
- **Реализация**: обычно с помощью **кучи (heap)** — бинарная куча, где:
    - Max-heap: корень — максимальный элемент
    - Min-heap: корень — минимальный элемент

| Операция                 | Сложность | Описание                                           |
| ------------------------ | --------- | -------------------------------------------------- |
| insert (добавление)      | O(log n)  | Добавление элемента и восстановление свойства кучи |
| extract (удаление корня) | O(log n)  | Удаление элемента с наивысшим приоритетом          |
| peek / top               | O(1)      | Просмотр корня                                     |
- **Применение**:
    - Алгоритмы Дейкстры / A*
    - Планирование задач по приоритету
    - Сортировка кучей (HeapSort)
