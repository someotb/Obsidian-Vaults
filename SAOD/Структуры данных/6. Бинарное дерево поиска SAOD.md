**Принцип работы:**

- Каждый узел имеет **ключ**, левое поддерево содержит элементы **меньше ключа**, правое — **больше ключа**.
- Позволяет быстро искать, вставлять и удалять элементы.

**Основные операции:**

|Операция|Сложность|Комментарий|
|---|---|---|
|Поиск (search)|O(h)|h — высота дерева; O(log n) для сбалансированного, O(n) в худшем случае|
|Вставка (insert)|O(h)|Поиск позиции + вставка|
|Удаление (delete)|O(h)|Найти элемент + перестановка узлов|
|Обход (traversal)|O(n)|In-order, pre-order, post-order|

**Особенности:**

- Эффективно для динамических данных с быстрым поиском.
- Может стать несбалансированным → худшая сложность O(n).
- Сбалансированные BST: AVL, Red-Black Tree (гарантируют O(log n) высоту).
