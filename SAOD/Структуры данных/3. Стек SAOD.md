- **Принцип**: Last In, First Out — последний вошёл, первый вышел.

| Операция | Сложность | Описание                                 |
| -------- | --------- | ---------------------------------------- |
| push     | O(1)      | Добавление элемента в вершину стека      |
| pop      | O(1)      | Удаление верхнего элемента               |
| top/peek | O(1)      | Получение верхнего элемента без удаления |

- **Применение**:
	- Отмена действий (undo)
	- Рекурсия
	- Проверка скобок
	- Обход графов (DFS)
- **Реализация**:
    - [[1. Массивы SAOD]] (фиксированный размер или динамический)
    - [[2. Списки SAOD]] (вставка/удаление с головы)
