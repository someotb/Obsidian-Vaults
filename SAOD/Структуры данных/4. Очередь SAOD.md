- **Принцип**: First In, First Out — первый вошёл, первый вышел.

| Операция             | Сложность | Описание                    |
| -------------------- | --------- | --------------------------- |
| enqueue (добавление) | O(1)      | Добавление элемента в конец |
| dequeue (удаление)   | O(1)      | Удаление элемента из головы |
| front (просмотр)     | O(1)      | Посмотреть первый элемент   |
- **Применение**:
    - Буферы ввода-вывода
    - Планировщики задач
    - BFS (обход в ширину графа)
- **Реализация**:
    - [[1. Массивы SAOD]] с кольцевым буфером
    - [[2. Списки SAOD]] с указателями head/tail
