**Принцип работы:**

- Полное [[6. Бинарное дерево поиска SAOD]] (каждый уровень заполнен слева направо).
- Два типа:
    - **Max-Heap**: родитель ≥ детей → корень = максимальный элемент
    - **Min-Heap**: родитель ≤ детей → корень = минимальный элемент

**Основные операции:**

|Операция|Сложность|Комментарий|
|---|---|---|
|Вставка (insert)|O(log n)|Добавляем элемент в конец + просеивание вверх|
|Извлечение корня (extract-max/min)|O(log n)|Меняем корень с последним элементом + просеивание вниз|
|Просмотр корня (peek/top)|O(1)|Только посмотреть элемент с наивысшим приоритетом|
|Построение кучи из массива|O(n)|Bottom-up heapify|

**Особенности:**

- Эффективно для очередей с приоритетами.
- Часто используется в **HeapSort** и алгоритмах Дейкстры/Прима.
- **Не стабильная** структура.
