|Структура данных|Основные операции|Доступ/Поиск|Вставка|Удаление|Память|Особенности|
|---|---|---|---|---|---|---|
|**Массив (Array)**|arr[i], добавление в конец|O(1)|O(n) (если не в конец)|O(n)|O(n)|Случайный доступ быстрый, память непрерывна|
|**Динамический массив (Vector/ArrayList)**|push_back, pop_back|O(1)|O(1) амортизировано|O(n)|O(n)|Автоматически расширяется, случайный доступ быстрый|
|**Односвязный список (Singly Linked List)**|push_front/back, delete, search|O(n)|O(1) если есть указатель|O(1) если есть указатель|O(n + указатели)|Нет случайного доступа, эффективны вставки/удаления|
|**Двусвязный список (Doubly Linked List)**|push_front/back, delete, search|O(n)|O(1)|O(1)|O(n + 2 указателя)|Есть prev/next, можно идти в обе стороны|
|**Стек (Stack, LIFO)**|push, pop, top|O(1)|O(1)|O(1)|O(n)|Последний вошёл — первый вышел, часто реализуется списком или массивом|
|**Очередь (Queue, FIFO)**|enqueue, dequeue, front|O(1)|O(1)|O(1)|O(n)|Первый вошёл — первый вышел, часто реализуется списком или кольцевым массивом|
|**Очередь с приоритетом / Куча (Heap / Priority Queue)**|insert, extract-max/min, peek|O(n) линейный поиск, O(1) peek|O(log n)|O(log n)|O(n)|Элемент с наивысшим приоритетом извлекается первым, бинарная куча|
|**Хеш-таблица (Hash Table)**|insert, search, delete|O(1) среднее|O(1) среднее|O(1) среднее|O(n)|Быстрый доступ по ключу, возможны коллизии|
|**Дерево поиска (BST)**|insert, search, delete|O(log n) сбалансированное|O(log n)|O(log n)|O(n)|Элемент слева < узла, справа > узла; хуже O(n) для несбалансированного|
|**Дерево отрезков / Fenwick Tree**|update, query|O(log n)|O(log n)|O(log n)|O(n)|Используется для сумм/минимумов/максимумов по диапазону|
|**Граф (список смежности)**|add_edge, neighbors|O(V+E)|O(1)|O(1)|O(V+E)|Эффективно для разреженных графов|
|**Граф (матрица смежности)**|add_edge, neighbors|O(1)|O(1)|O(1)|O(V²)|Эффективно для плотных графов, быстрый доступ|
