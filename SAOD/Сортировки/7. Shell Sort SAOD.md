# **Сортировка Шелла (Shell Sort)**

**Принцип работы:**

- Улучшение **сортировки вставками**.
- Основная идея: сначала сортируем элементы, находящиеся на определённом **шаге (gap)** друг от друга.
- Постепенно уменьшаем шаг до 1 и выполняем обычную сортировку вставками.
- Это позволяет **уменьшить количество перемещений** и ускоряет работу на больших массивах.

**Схема работы (пример):**

```
Массив: [8, 5, 3, 7, 6, 2, 4, 1]
1. Gap = 4 → сравниваем элементы на расстоянии 4
   [8,5,3,7,6,2,4,1] → частично упорядоченный массив
2. Gap = 2 → сортировка вставками по подмассивам с шагом 2
3. Gap = 1 → обычная сортировка вставками → окончательно отсортированный массив
```

# **Сложность Shell Sort**

| Случай  | Время                                                     | Память |
| ------- | --------------------------------------------------------- | ------ |
| Лучший  | O(n log² n) (зависит от последовательности шагов)         | O(1)   |
| Худший  | O(n²) (для простой последовательности)                    | O(1)   |
| Средний | O(n^(3/2)) до O(n^(4/3)) (оптимальные последовательности) | O(1)   |

**Особенности:**

- **In-place сортировка** — память O(1).
- **Не стабильная** сортировка.
- Эффективна для массивов среднего размера.
- Выбор последовательности шагов (gap sequence) сильно влияет на производительность (Shell, Hibbard, Sedgewick и др.).
