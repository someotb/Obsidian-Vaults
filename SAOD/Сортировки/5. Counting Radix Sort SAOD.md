# **1. Counting Sort (Сортировка подсчётом)**

**Принцип работы:**

- Используется для **целых чисел в ограниченном диапазоне [0..k]**.
- Считаем, сколько раз встречается каждый элемент.
- Затем восстанавливаем отсортированный массив, используя эти счётчики.

**Схема работы:**

```
Массив: [4,2,2,8,3,3,1]
1. Создаём массив счетчиков count[0..8] → подсчитываем количество каждого числа
2. Вычисляем префиксные суммы (для стабильности)
3. Формируем отсортированный массив
Результат: [1,2,2,3,3,4,8]
```

**Сложность:**

|Случай|Время|Память|
|---|---|---|
|Все случаи|O(n + k)|O(n + k)|

**Особенности:**

- Стабильная сортировка.
- Очень быстрая для небольшого диапазона значений.
- **Не сравнивает элементы** напрямую.

# **2. Radix Sort (Поразрядная сортировка)**

**Принцип работы:**

- Используется для **чисел или строк фиксированной длины**.
- Сортировка выполняется по **разрядам (цифрам)**, начиная с младшего (LSD) или старшего (MSD).
- На каждом шаге часто используют **Counting Sort** для стабильной сортировки по разряду.

**Схема работы (LSD):**

```
Массив: [170, 45, 75, 90, 802, 24, 2, 66]
1. Сортируем по единицам → [170, 90, 802, 2, 24, 45, 75, 66]
2. Сортируем по десяткам → [802, 2, 24, 45, 66, 170, 75, 90]
3. Сортируем по сотням → [2, 24, 45, 66, 75, 90, 170, 802]
```

**Сложность:**

|Случай|Время|Память|
|---|---|---|
|Все случаи|O(d*(n + k))|O(n + k)|

- `d` — число разрядов
- `k` — диапазон цифр (0–9 для десятичной системы)

**Особенности:**

- Стабильная сортировка.
- Отлично работает для больших массивов чисел с небольшим диапазоном разрядов.
- Может быть быстрее O(n log n) для ограниченного диапазона и фиксированной длины.
