|Сортировка|Принцип|Сложность (Лучший)|Сложность (Средний)|Сложность (Худший)|Память|Стабильность|Особенности|
|---|---|---|---|---|---|---|---|
|**Bubble Sort**|Сравнение соседних элементов и обмен|O(n) (с оптимизацией)|O(n²)|O(n²)|O(1)|✔|Простой, медленный, стабилен|
|**Insertion Sort**|Вставка элемента в отсортированную часть|O(n)|O(n²)|O(n²)|O(1)|✔|Хорошо для почти отсортированных массивов|
|**Selection Sort**|Поиск минимального элемента и обмен|O(n²)|O(n²)|O(n²)|O(1)|✖|Всегда делает n² сравнений, мало обменов|
|**Quick Sort**|Разделяй и властвуй, выбираем pivot|O(n log n)|O(n log n)|O(n²)|O(log n)|✖|Быстрая для больших массивов, выбор pivot важен|
|**Merge Sort**|Разделяй и властвуй, слияние подмассивов|O(n log n)|O(n log n)|O(n log n)|O(n)|✔|Стабильная, требует доп. памяти|
|**Heap Sort**|Построение кучи и извлечение корня|O(n log n)|O(n log n)|O(n log n)|O(1)|✖|Не стабильная, in-place|
|**Counting Sort**|Счёт количества элементов|O(n+k)|O(n+k)|O(n+k)|O(n+k)|✔|Только для целых чисел с небольшим диапазоном|
|**Radix Sort**|Поразрядная сортировка с использованием Counting Sort|O(d*(n+k))|O(d*(n+k))|O(d*(n+k))|O(n+k)|✔|Для чисел или строк фиксированной длины|
|**Shell Sort**|Сортировка вставками с шагом (gap)|O(n log² n)|O(n^(3/2))–O(n^(4/3))|O(n²)|O(1)|✖|Эффективно для средних массивов, выбор последовательности gap важен|
