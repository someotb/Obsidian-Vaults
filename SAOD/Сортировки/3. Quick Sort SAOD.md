**Принцип работы:**

- Алгоритм использует **метод «разделяй и властвуй» (divide & conquer)**.

1. Выбираем **опорный элемент (pivot)**.
2. Разбиваем массив на два подмассива:
    - элементы **меньше pivot**,
    - элементы **больше pivot**.
3. Рекурсивно сортируем оба подмассива.
4. Соединяем результаты — массив отсортирован.

**Схема работы:**

```
Массив: [5, 3, 8, 4, 2] 
Выбираем pivot = 4 
Меньше: [3, 2], pivot: [4], Больше: [5, 8] 
Рекурсивно сортируем [3, 2] → [2, 3] 
Рекурсивно сортируем [5, 8] → [5, 8] 
Объединяем → [2, 3, 4, 5, 8]
```

# **Сложность Quicksort**

|Случай|Время|Память|
|---|---|---|
|Лучший (равномерное деление)|O(n log n)|O(log n) рекурсия|
|Худший (массив уже отсортирован, плохой pivot)|O(n²)|O(n) рекурсия|
|Средний|O(n log n)|O(log n) рекурсия|

**Особенности:**

- Быстро работает на больших массивах.
- Обычно рекурсивная реализация, можно оптимизировать итеративно.
- **Не стабильная** сортировка (порядок равных элементов может измениться).
- Выбор pivot важен для производительности: часто берут случайный элемент или median-of-three.
