# **Сортировка выбором (Selection Sort)**

**Принцип работы:**

- Идём по массиву и **находим минимальный элемент** в оставшейся части.
- Меняем его с элементом на текущей позиции.
- Повторяем для всех позиций массива.

**Схема работы:**

```
Массив: [64, 25, 12, 22, 11]
1. Находим min=11 → меняем с 64 → [11, 25, 12, 22, 64]
2. Находим min=12 → меняем с 25 → [11, 12, 25, 22, 64]
3. Находим min=22 → меняем с 25 → [11, 12, 22, 25, 64]
4. Находим min=25 → уже на месте → [11, 12, 22, 25, 64]
```

---

# **Сложность Selection Sort**

|Случай|Время|Память|
|---|---|---|
|Лучший|O(n²)|O(1)|
|Худший|O(n²)|O(1)|
|Средний|O(n²)|O(1)|

**Особенности:**

- **Не стабильная сортировка** (порядок равных элементов может измениться).
- Простая реализация.
- Эффективна только для **малых массивов**.
- Всегда делает **n(n−1)/2 сравнений**, но минимум обменов — n.
