
- - -

**Принцип:**

- Проходим массив **последовательно** от начала до конца.
- Сравниваем каждый элемент с нужным значением.
- Если нашли — возвращаем индекс, если нет — элемент отсутствует.

**Сложность:**

| Случай                  | Время | Память |
| ----------------------- | ----- | ------ |
| Лучший (элемент первый) | O(1)  | O(1)   |
| Худший / Средний        | O(n)  | O(1)   |

**Применение:**

- Массив не отсортирован.
- Малые размеры данных.

**Особенности:**

- Простая реализация.
- Неэффективен на больших данных.
