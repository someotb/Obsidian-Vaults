## Что такое цифровой фильтр?

Цифровой фильтр (ЦФ) — это **линейная дискретная система**, которая преобразует входную последовательность отсчётов $$ x(n) $$ в выходную $$ y(n) $$ по заданному алгоритму, реализуемому программно или аппаратно.

Основное назначение цифрового фильтра — **частотная селекция**: выделение или подавление определённых участков спектра сигнала. Например:
- фильтр низких частот (ФНЧ) — пропускает низкие частоты,
- фильтр высоких частот (ФВЧ) — пропускает высокие,
- полосовой фильтр (ПФ) — пропускает диапазон частот.

---

## Типы цифровых фильтров

### КИХ-фильтр (FIR — Finite Impulse Response)

Выход зависит только от входа:

$$
y(n) = \sum_{i=0}^{N} b_i x(n - i)
$$

- Импульсная характеристика конечна,
- Всегда устойчив,
- Может иметь линейную ФЧХ → **без фазовых искажений**.

### БИХ-фильтр (IIR — Infinite Impulse Response)

Выход зависит и от входа, и от предыдущих выходов:

$$
y(n) = \sum_{i=0}^{N} b_i x(n - i) - \sum_{k=1}^{M} a_k y(n - k)
$$

- Импульсная характеристика теоретически бесконечна,
- Требует проверки устойчивости,
- Эффективен при малом числе коэффициентов.

## Порядок расчёта цифрового фильтра

1. **Определить тип фильтра**: ФНЧ, ФВЧ, ПФ.
2. **Задать параметры**:
   - частота дискретизации $$ f_d $$
   - частота среза $$ f_c $$
   - допустимые пульсации в полосе пропускания и подавления.
3. **Выбрать метод синтеза**:
   - для КИХ: оконный метод, метод Паркс-Макклеллана,
   - для БИХ: билинейное преобразование аналогового прототипа (Баттерворта, Чебышёва и др.).
1. **Вычислить коэффициенты** $$ b_i, a_k $$
2. **Реализовать фильтр в коде или схеме**.
3. **Проверить АЧХ/ФЧХ и протестировать на сигнале**.

---

## Как применяется цифровой фильтр?

- В аудиообработке (подавление шума, эквалайзеры),
- В телекоммуникациях (выделение каналов),
- В измерительных системах (сглаживание данных),
- В медицинской электронике (ЭКГ, ЭЭГ),
- В радиосвязи (демодуляция, подавление помех).

## Письменный пример: КИХ-ФНЧ по оконному методу

Пусть требуется спроектировать ФНЧ с:
- частотой дискретизации $$ f_d = 8000\ Гц,$$
- частотой среза $$ f_c = 1000\ Гц,$$
- длиной фильтра $$ N = 51\ (нечётное).$$

1. Нормированная частота среза:  
   $$ \Omega_c = \frac{2\pi f_c}{f_d} = \frac{2\pi \cdot 1000}{8000} = 0.25\pi $$

2. Идеальная импульсная характеристика:  
   $$ h_d(n) = \frac{\sin(\Omega_c (n - 25))}{\pi (n - 25)},\quad n = 0, 1, \dots, 50 $$

3. При $$ n = 25 $$$$ h_d(25) = \frac{\Omega_c}{\pi} = 0.25 $$

4. Применяем окно Хэмминга:  
   $$ w(n) = 0.54 - 0.46 \cos\left( \frac{2\pi n}{50} \right) $$

5. Итоговая ИХ:  
   $$ h(n) = h_d(n) \cdot w(n) $$

Полученный фильтр будет иметь линейную ФЧХ и подавлять частоты выше 1 кГц.

## Пример на Python (КИХ-ФНЧ с помощью `scipy`)

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy.signal import freqz, lfilter, windows

f1 = 3000
f2 = 6000
fs = 8000
fc = 2500
T = 1 / fs

omega_c = 2*np.pi*fc/fs
t = np.arange(0, 1, T)
print(f'Omega_c: {omega_c}')
s = np.sin(2*np.pi*f1*t) + np.cos(2*np.pi*f2*t)

N = len(s)

# plt.figure(1)
# plt.plot(t, s, 'r')
# plt.stem(t, s, 'b--' ,basefmt=" ")
# plt.grid()
# plt.title("Исходный дискретный сигнал")

amp = np.fft.fftshift(np.fft.fft(s))
freq = np.fft.fftshift(np.fft.fftfreq(N, T))

plt.figure(2)
plt.plot(freq, np.abs(amp))
plt.title("Спектр исходного сигнала")
plt.grid()

N_h = 55
M = (N_h - 1) // 2
n = np.arange(-M, M + 1)

h = np.zeros(N_h)

for i, k in enumerate(n):
	if k == 0:
		h[i] = omega_c / np.pi # = 2*fc/fs
	else:
		h[i] = np.sin(omega_c * k) / (np.pi * k)

h_hpf = np.zeros_like(N_h)

for i, k in enumerate(n): # n = [-M, ..., M]
	if k == 0:
		h_hpf[i] = 1.0 - omega_c / np.pi
	else:
		h_hpf[i] = -np.sin(omega_c * k) / (np.pi * k)

h_amp = np.fft.fftshift(np.fft.fft(h))
freq = np.fft.fftshift(np.fft.fftfreq(len(h), N_h))

window = np.hamming(N_h)
h_windowed = h * window

plt.figure(3)
plt.plot(freq, np.abs(h_amp))
plt.title("ИХ")
plt.grid()

filtered_s = np.convolve(s, h_windowed, mode='same')
amp = np.fft.fftshift(np.fft.fft(filtered_s))
freq = np.fft.fftshift(np.fft.fftfreq(len(filtered_s), T))
  
plt.figure(4)
plt.plot(freq, np.abs(amp))

plt.show()
```
