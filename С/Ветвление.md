Обычное ветвление(более быстрое чем каскадное, но менее читаемое) [[Условный оператор if|С++]]
```c
#include<stdio.h>

int main()
{
int a;
printf("Введите число для сравнения с 0: ");
scanf("%d", &a);
if(a > 0) printf("Число %d > 0", a);
else printf("Число %d < 0", a);
}
```

Каскадное ветвление(более читаемое, но медленнее обычного)
```c
#include<stdio.h>

int main()
{
int x, y;
printf("\nВведите координаты: ");
scanf("%d%d", &x, &y);
if(x > 0 and y > 0) printf("Первая четверть\n");
else if (x < 0 and y > 0) printf("Вторая четверть\n");
else if (x > 0 and y < 0) printf("Третья четверть\n");
else if (x > 0 and y < 0) printf("Четвертая четверть\n");
}
```
